ÉTAPE 5 — CONFIGURER LE PULSE CHARIOW (dans le tableau de bord Chariow)
════════════════════════════════════════════════════════════════════════════════
Automation → Pulses → Add Pulse :
  - URL : https://nexirole.vercel.app/api/webhooks/chariow
  - Événements : successful.sale, license.issued, license.activated,
                 license.revoked, license.expired
  - Notez le secret (whsec_...) → CHARIOW_WEBHOOK_SECRET
En local, utilisez un tunnel HTTPS (ngrok / VS Code Dev Tunnels) et l'URL
publique correspondante + ?secret=whsec_xxx n'est PAS nécessaire : le header
de signature suffit.
